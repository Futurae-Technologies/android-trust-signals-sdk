TSLegacy Schedule Exception

class TSLegacyScheduleException(message: String = "This scheduled collection was created by an earlier SDK version and is no longer " + "supported, so it has been cancelled. Call scheduleCollections again with a complete " + "TSCredentials to resume collections.") : Exception

Delivered to the handler registered via com.futurae.sdk.ts.TrustSignalsSDK.registerErrorHandler when a scheduled collection created by an earlier SDK version runs after an upgrade.

Such schedules were created with appId and lack the identifiers now required by the server (serviceId, unitId, interactionId, verificationStatus), or with a base serverURL instead of the full collectionUrl. The SDK cancels the outdated schedule automatically; call com.futurae.sdk.ts.TrustSignalsSDK.scheduleCollections again with a complete com.futurae.sdk.ts.model.public.TSCredentials to resume collections.
