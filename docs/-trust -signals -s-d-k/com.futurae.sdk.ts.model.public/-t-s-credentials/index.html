TSCredentials

data class TSCredentials(val accountId: String, val accessToken: String, val serviceId: String, val unitId: String, val interactionId: String, val verificationStatus: TSVerificationStatus)

Credentials and identifiers used for a collect-and-upload operation.

Parameters

accountId

Account identifier sent in the upload request body.

accessToken

Bearer token used to authenticate the upload.

serviceId

Caller-supplied tenant identifier (UUID). Not derived from the access token.

unitId

Mobile app identifier, e.g. futapp-android. Letters, numbers and -, max 1000 characters.

interactionId

Per-installation identifier: <installationUUID> or <installationUUID>-<sessionId>. Letters, numbers and -, max 1000 characters.

verificationStatus

Outcome of the host app's own verification of this interaction.

Throws

IllegalArgumentException

if any identifier does not match its required format.
